Assertions I live by

The rules I build into every test and every tool.

expect(verdict).toCite(evidence)

Evidence over opinion

No screenshot, log or record means the result is inconclusive, never a pass.

afterEach(cleanUp)

Tests clean up after themselves

Every test that creates data removes it. Nothing depends on a manual reset.

test.each(envs)

One test, every environment

No hardcoded hosts or data. The same test runs on dev and staging unchanged.

expect(prod).not.toBeTouched()

Safe by default

Nothing writes data unless the environment explicitly allows it. Secrets never reach the model.
